## Implementation

- Added clear repository validation for required names, phone values, review
  messages, HTTPS social links, approved categories, and the existing 4,000
  character public-message policy.
- Added URL and telephone input semantics without changing field placement or
  visual styling.
- Added matching 4,000-character limits to both visible public message fields.
- Admin content now rehydrates from Supabase whenever an authenticated admin
  section is opened.
- Query and estimate totals now refresh when a logged-in admin submits either
  public form and whenever the dashboard is opened.
- Logout clears cached admin totals.
- Review and settings writes continue to call `refreshContent()` so the same
  database result immediately drives the public site in the admin's browser.

## Public attachment controls

The existing visual photo-attachment areas are not enabled in Step 6. The only
Cloudinary signing endpoint is correctly restricted to authenticated admins.
Allowing anonymous visitors to request signed uploads without Turnstile and
rate limiting would expose the client's Cloudinary quota to abuse. This must be
resolved in the security/failure-mode step before public attachment upload can
be honestly approved.
